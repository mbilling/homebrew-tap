# mbilling/homebrew-tap

Homebrew formulae for [fss-mqtt](https://github.com/mbilling/fss-mqtt), an interactive terminal
MQTT v5 explorer. Works on macOS and Linux.

```sh
brew install mbilling/tap/fss-mqtt
brew upgrade fss-mqtt      # later releases
```

`Formula/fss-mqtt.rb` is updated automatically by the fss-mqtt release workflow; don't edit it by
hand.
